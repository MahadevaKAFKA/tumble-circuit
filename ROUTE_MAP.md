## Module contract
Each module = consecutive pieces sharing a `Segment`. Ports are the first/last generated cross-sections: position, forward tangent, up, width, route distance S. `TrackValidator` requires exit == next entry (≤ 0.01 studs), same facing (dot ≥ 0.9999) and width, positive route length, 8–20 grid slots, dividers that rejoin, hazards with a controller, hammer inside the lane for every seed, falling tiles passable for every seed (≥ 2 solid per row and a shared solid column between rows), sweeper speed and fan cycle in range. Hazard sockets are piece-relative (`Piece` + `At`/`From`/`To` + lateral `Offset`). Reset hooks: hazards are pure functions of (seed class, serverTime − epoch); tiles are toggled by HazardService; nothing accumulates between rounds.

## Hazard seed classes
Round N uses class N mod 3. Class 0 = definition values; classes 1 and 2 override (HazardSim.Variants): sweeper direction/speed, hammer period/phase, tile pattern offset/period, fan direction/timing, conveyor direction/strength, bumper phase offsets.
